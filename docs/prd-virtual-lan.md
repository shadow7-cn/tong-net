# 同网互通组网服务 PRD

> 状态：已确认，进入实现
> 版本：0.2.0
> 平台：Linux Docker、Windows、macOS

## 1. 产品概述

同网互通组网服务用于帮助不同真实网络中的设备建立 EasyTier 虚拟局域网。管理员在 Linux 服务器上通过 Docker 从源码构建并运行服务，浏览器进入统一风格的管理后台；Windows、macOS 同网互通桌面端填写服务器地址、网络名称、网络密码和设备名称后加入虚拟网络。

组网服务与聊天、文件传输是两个独立功能：

- 组网服务只负责 EasyTier 网络、节点状态和私有网络设备授权。
- 同网互通桌面 App 继续负责聊天和文件服务。
- 虚拟局域网页中的成员列表仅展示信息，点击成员不执行跳转。
- App 首页在组网成功后显示本机虚拟局域网访问地址和二维码。
- Linux 服务不保存聊天、文件、聊天记录或文件名。

## 2. 产品原则

- 免费、开源、自行部署。
- 单 Docker 镜像、单容器、单数据目录。
- 管理 UI 与同网互通桌面端保持一致。
- 默认简单，隐藏普通用户不需要理解的 EasyTier 内部参数。
- 支持公共节点和私有节点两种互斥运行模式。
- 默认私有节点模式。
- 公共节点优先开放易用，私有节点优先设备可撤销。
- 第一版从服务器源码构建 Docker，不发布镜像市场。
- Docker 镜像市场和 1Panel 应用包放到后续版本，但部署结构必须兼容。

## 3. 角色

### 3.1 管理员

首次进入 Linux Web 时自行创建管理员用户名和密码。管理员管理节点模式、私有网络、设备、操作记录和站点设置。

### 3.2 桌面设备

一台同网互通桌面安装对应一个稳定设备 ID。用户可以设置设备名称，名称允许重复；系统始终使用设备 ID 区分身份。

## 4. 两种节点模式

一台服务器同一时间只能运行一种模式。切换模式会断开当前连接并重启 EasyTier，切换前要求输入管理员密码确认。

### 4.1 公共节点模式

- 桌面用户自由填写网络名称和网络密码。
- 相同网络名称和密码的设备进入同一网络。
- 网络名称和密码只保存在桌面端，不发送给 Linux 管理 API。
- Linux 服务器作为共享节点，帮助发现、打洞和中继。
- 管理后台只展示 EasyTier 能观察到的节点、协议、延迟和流量。
- 不按网络管理设备，不提供单设备撤销。
- 不自动提交到任何公共节点列表。
- 不做流量配额和限速，后台显示流量并持续提示带宽风险。

### 4.2 私有节点模式

- 管理员在 Web 后台创建私有网络。
- 最多创建 10 个网络。
- 网络名称全站唯一，创建后不可修改。
- 网络密码创建时可输入或随机生成，只显示一次；服务端只保存 Argon2id 哈希。
- 用户在桌面端填写公开网络名称和密码。
- 服务端校验后，返回隐藏的 EasyTier 内部网络名称及该设备的独立凭据。
- EasyTier 主网络密码、固定私钥和内部名称由服务生成，对管理员和桌面用户隐藏。
- 每个网络使用独立凭据库和管理实例。
- 共享节点通过中继网络白名单只允许后台创建的私有网络。
- 修改网络密码会撤销该网络全部设备会话和凭据，其他网络不受影响。

## 5. 首次初始化

首次进入 `http://服务器地址:Web端口` 时直接显示初始化向导，不使用一次性初始化码。

步骤：

1. 创建管理员用户名和密码。
2. 设置站点名称、对外 IP 或域名。
3. 选择公共节点或私有节点模式，默认私有。
4. 私有模式必须创建第一个网络；公共模式跳过。
5. 初始化完成后永久关闭初始化入口。

密码规则：

- 管理员密码和私有网络密码至少 8 个字符。
- 密码输入框提供随机按钮。
- 随机密码由浏览器本地生成 20 位大小写字母和数字。

未初始化服务存在被抢先创建管理员的风险，本产品不额外阻止；管理页面提醒公网部署者立即完成初始化。

## 6. 管理 Web

主页面：

### 6.1 概览

- 当前公共/私有模式。
- 管理服务和 EasyTier 状态。
- Web 与 EasyTier 当前端口。
- 在线连接数。
- 当前速率和累计流量。
- 版本、运行时间和最近错误。

### 6.2 网络

私有模式可用：

- 创建网络。
- 显示网络状态和设备数量。
- 停用网络。
- 重置网络密码。
- 删除已停用且无在线设备的网络。

公共模式下菜单禁用，并说明网络由桌面端自行决定。

### 6.3 设备

私有模式：

- 按网络筛选设备。
- 展示用户设备名称、管理员备注、虚拟 IP、平台、版本、在线状态、协议、延迟和最后在线时间。
- 允许修改管理员备注。
- 在线或离线设备均可撤销。
- 只有已撤销且离线的设备成员关系可以删除。

同一设备可以加入多个私有网络。撤销只针对当前网络，不影响其他网络。

公共模式：

- 仅展示 EasyTier 可观察到的连接信息。
- 不承诺识别真实设备身份、网络归属或执行撤销。

### 6.4 操作记录

记录管理员登录、初始化、模式切换、网络创建/停用/删除、密码重置、设备加入/撤销、EasyTier 启停和异常。

- 保留 90 天或最近 10,000 条，以先达到者为准。
- 支持分页、类型筛选和手动清空。
- 清空行为自身写入新记录。
- 不记录密码、令牌、EasyTier 凭据或业务内容。

### 6.5 设置

- 站点名称。
- 对外 IP 或域名。
- 当前模式及切换。
- 管理员用户名和密码修改。
- Web 与 EasyTier 端口只读展示。
- 服务版本、EasyTier 版本、许可证和诊断信息。

管理 UI 桌面优先，手机可完成初始化、登录、查看、修改密码、创建网络和撤销设备。手机端导航使用抽屉，表格切换为紧凑列表。

## 7. 桌面端

### 7.1 配置

桌面端只保存最近一个配置，同时只连接一个虚拟网络：

- 完整服务器 URL，例如 `http://43.162.103.53:17280`。
- 网络名称。
- 网络密码。
- 设备名称。

网络密码继续使用现有 AES-256-GCM 本地加密保存。

### 7.2 连接

1. 请求服务器公开信息，获取模式、EasyTier 端口和服务器公钥。
2. 公共模式：网络名称和密码只交给本机 EasyTier Core。
3. 私有模式：通过管理 API 校验网络名称和密码，登记网络设备成员，取得独立 EasyTier 凭据。
4. 桌面端启动现有 EasyTier 系统服务。
5. 显示虚拟 IP、成员、协议、延迟、流量和诊断日志。

虚拟局域网保持手动连接。软件启动时自动填充已保存配置，但不自动启动 EasyTier。

### 7.3 HTTP 提示

- HTTP 允许使用。
- 第一次连接某个 HTTP 服务器时提示“连接未加密”并要求确认。
- 确认结果按服务器地址保存。
- 页面持续显示低干扰“未加密”标签。
- HTTPS 不提示。

### 7.4 设备状态

私有模式连接期间每 10 秒发送心跳，30 秒无心跳判定离线。正常断开只结束会话并停止 Core，不撤销设备凭据。

如果本地凭据丢失，服务端撤销旧凭据并为同一设备 ID 签发新凭据。

设备名称：

- 用户可随时修改。
- 允许重复。
- 长度 1 至 40 个 Unicode 字符。
- 不允许控制字符。
- 改名不改变设备 ID 或凭据。

## 8. 设备撤销

私有网络中：

- 撤销设备成员关系后，其会话和该网络的 EasyTier 凭据失效。
- 同一设备 ID 不能直接重新加入该网络。
- 删除已撤销且离线的成员关系后，知道当前网络密码的用户可以重新加入。
- 修改网络密码是清退仍知道旧密码使用者的可靠方式。

公共模式不提供设备撤销。

## 9. Docker

默认端口：

- `17280/TCP`：管理 Web 与 API。
- `11010/TCP+UDP`：EasyTier。

端口通过 Docker 环境变量配置，管理 UI 只读展示。由于使用 `network_mode: host`，修改的是程序实际监听端口，而不是端口映射。

容器需要：

- `NET_ADMIN`
- `NET_RAW`
- `/dev/net/tun`
- 持久化 `/data`

所有需要备份的数据位于 `/data`。第一版只提供停止容器后备份/恢复整个 `/data` 的文档，不做备份 UI。

## 10. 管理员恢复

忘记管理员密码时，通过服务器本地命令重置：

```bash
docker exec -it tong-net-server tong-net-server admin reset-password
```

重置后管理员已有会话全部失效，网络和设备数据不受影响。

## 11. 版本与发布范围

- 桌面端和 Linux 组网服务统一为 `0.2.0`。
- 第一版在测试服务器上从源码构建 Docker。
- 暂不发布 GHCR、Docker Hub 或镜像市场。
- 暂不制作 1Panel 应用包。
- Dockerfile、Compose、持久化和配置结构必须为后续发布做好兼容。
- Windows 本轮完成编译和打包验证；真机 UAC、Service 和 TUN 验收后补。

## 12. 安全要求

- 管理员密码和私有网络密码使用 Argon2id。
- 私有网络内部秘密使用 AES-256-GCM 加密。
- EasyTier RPC 只监听 localhost。
- 不挂载 Docker Socket。
- UI 不接受任意命令或 EasyTier 参数。
- 公共模式网络密码不进入 Linux API、数据库和日志。
- 私有模式使用 Secure Mode 和单设备凭据，不允许回退为向桌面端下发主网络密码。
- HTTP 只适合测试和可信网络；生产环境由外部反向代理提供 HTTPS。
- 镜像保留 EasyTier LGPL-3.0 许可证和版本来源。

## 13. 非目标

- 组网成员点击跳转聊天。
- Linux 云端聊天或文件服务。
- 多管理员和角色。
- 独立访问账号体系。
- 桌面端保存多个网络配置。
- 自动连接虚拟网络。
- 公共节点流量配额和限速。
- 第一版镜像市场和 1Panel 上架。
- 浏览器直接加入 EasyTier。
- 手机原生客户端。

## 14. 验收标准

1. Ubuntu 服务器可以从源码构建单 Docker 镜像并启动。
2. 首次初始化能创建管理员、选择模式并创建首个私有网络。
3. 公共模式允许两个任意同名同密码桌面节点组网，网络密码不经过管理 API。
4. 私有模式支持最多 10 个网络，单个 `11010/TCP+UDP` 端口完成中继。
5. 私有网络设备使用独立 Secure Mode 凭据。
6. 撤销一个网络中的设备不影响其他设备或其他网络。
7. 修改网络密码只让该网络全部设备重新登录。
8. 模式切换保留私有网络数据并断开当前连接。
9. Linux 管理 UI 与桌面端视觉统一并支持手机操作。
10. 桌面端保存最近配置、手动连接并展示成员状态。
11. App 首页在连接后显示虚拟地址与二维码。
12. 自定义 Web/EasyTier 端口能正确下发。
13. 容器重启、删除重建和 `/data` 恢复不丢失身份。
14. Core 崩溃可诊断并按退避策略重启。
15. 本地前后端测试、Rust 测试、Docker 测试和真实组网测试通过。
16. 完成验证后清空测试数据，服务器停留在首次初始化页面。
